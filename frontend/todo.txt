```text

    ▼
```

# Step 1: Enrich your product data

Your products currently have fields like:

```js
{
  title,
  description,
  category,
  price,
  images
}
```

For AI recommendations, add richer metadata.

Example:

```js
{
  title: "Loadout 001",

  category: "Cargo",

  color: "Black",

  fit: "Relaxed",

  style: "Streetwear",

  season: "All Season",

  occasion: [
    "College",
    "Casual"
  ],

  material: "Cotton",

  gender: "Unisex",

  price: 1699
}
```

The richer the metadata, the better the recommendations.

---

# Step 2: Create embeddings

Instead of embedding only the description, create one descriptive sentence.

Example:

```text
Loadout 001

Category: Cargo Pants

Color: Black

Style: Minimal Streetwear

Fit: Relaxed

Occasion: College, Casual

Material: Cotton
```

Generate an embedding for this text and store it in Pinecone.

Metadata:

```js
{
  id: product._id,
  category: "cargo",
  color: "black",
  style: "streetwear",
  occasion: ["college"],
  price: 1699
}
```

---

# Step 3: Let the AI understand the query

User asks:

> Show me an all-black streetwear outfit under ₹4000.

Instead of searching directly, ask the LLM to extract filters.

Output:

```json
{
  "style": "streetwear",
  "color": "black",
  "budget": 4000,
  "intent": "complete outfit"
}
```

Now you have structured data.

---

# Step 4: Search

You now know:

```
style = streetwear

color = black

budget <= 4000
```

Use MongoDB:

```js
Product.find({
    style: "streetwear",
    color: "black",
    price: { $lte: 4000 }
})
```

or use Pinecone metadata filters.

---

without writing any filtering logic.
